Old weighted sampler conditions globally, implicitly weighting users by their catalog inclusion; measure this difference. Main change is dynamic fresh draws from the full eligible pool. No balancing by validation/test frequencies.

Hypotheses and falsifiers:
1. Fixed cap256/user reduces positive-target support. Controlled 8000-step seed11 fixed versus full-pool draws with identical model/optimizer/init. Falsified if support fails to increase; ranking benefit unsupported if paired user NDCG difference is uncertain/negative. Potential support and actually drawn support reported separately.
2. Pure GPT learning may improve with more diverse targets and bounded optimization search. Four pilot runs: fixed d128 lr3e-4 wd.01; dynamic same; dynamic d128 lr7e-4 wd.01; dynamic d192 lr3e-4 wd.05. Two layers, four heads, context64, batch64, warmup500 cosine decay (floor .1), 8000 steps; check2000. Select dynamic configuration by maximum validation NDCG20; fresh main fits24000 steps seeds11/29/47, same schedule, select checkpoint by NDCG20. Fixed-vs-dynamic effect only same-budget pilot comparison. Train probe CE and validation CE/ranking curves saved. No further search or extensions.
3. History copying explains part of ranking gap. Tune mixture alpha in {0,.25,.5,.75,.9} on validation NDCG20 per seed; fixed alpha used for both reference and RL. p=(1-alpha)p_GPT+alpha p_count; p_count = .999 normalized history counts +.001 train popularity (fallback popularity if empty). Also report count alone, popularity, and mixtures replacing GPT by popularity or uniform, with same alpha and separately best alpha including1. This distinguishes Transformer contribution from copying. Pure GPT always shown. If count/ablations match hybrid, Transformer gain unsupported.
4. Candidate features improve action-sensitive prediction beyond history. Fit history-only, candidate-only, joint interactions, and joint residual around available past completion mean. No user IDs as features. Fit weighted ridge penalties {.001,.01,.1} on <18M; hyper choose inner18-19M RMSE, affine calibration19-20M. Main RM chosen on policy validation using within-user centered MSE, subject total RMSE<=1.005 history-only; otherwise best joint is exploratory and signal gate fails. Gate requires paired user CI for centered MSE difference versus history-only entirely negative and total RMSE guard. Report MAE/RMSE/calibration, within/between decomposition, paired incremental errors, and matched-context within-user pairs with >=.2 response contrast, same 6h interval and past mean difference<=.05, distinct objects (at most20/user). Pairs are observational diagnostics, no causal item effects. Candidate item statistics use leave-one-out labels during fit. Independent evaluator: separate architecture/seed, never policy selection. If gate fails RL is explicitly a proxy sensitivity analysis.
5. RL improves proxy but may trade off relevance/duration/diversity. Freeze baseline and RM selection. Main runs3 seeds: H1raw640 steps, H5raw128 (equal40960 actions), H1 duration-corrected640; beta=.1 gamma=.9 RL lr5e-5. Keep existing correct REINFORCE return including future-state KL and detached action-independent baseline. SFT gets maximum RL body compute budget. Mixed top100 reranking lambda{0,2,5,10}, exact full-catalog q proportional reference*exp(r/beta). RL checkpoint0/half/end maximize raw reward under NDCG20>=.95 reference. H5 transition appends recommendation in artificial slate; feedback frozen. No user consumption simulated. Same repeat masks: past repeats allowed, within-list repeats forbidden for all methods. Raw unmasked list-repeat mass separate.
6. Longer horizon can increase disagreement/exploitation; compare step1..5 on real prefixes and synthetic continuation with shared masks and uniforms. Unsupported if disagreement has no reliable increase; disagreement does not establish true error.
