## Архивы завершённых экспериментов

**Публичные ссылки пока не предоставлены.** Эти названия не являются доступными удалёнными ресурсами. Их нужно отдельно предоставить проверяющему (например, attachment/release с неизменным SHA). Поле `url` в [configs/artifacts.json](../configs/artifacts.json) оставлено `null`; загрузчик ясно сообщает об отсутствии ссылки. GitHub URL исходного кода не заменяет ссылки на архивы.

| Архив | Bytes | SHA256 | Назначение |
|---|---:|---|---|
| study03_artifacts.zip | 2888029856 | 0ad895df71cad0b2945338cbee948ce0d149972d0973efe37cb0198d45127e29 | Frozen checkpoints/RM, подготовленные истории и train pool, per-event outputs, протокол provenance study_03 |
| submission_artifacts.zip | 1842192214 | 9349524b57091c54ffdd5b3ccbdc916aa693abfab151c080b3b8107597996fec | Frozen inputs study_04, pure RL/SFT веса, полная λ-сетка, outputs, selection и seals |

Размеры указаны для **исходных неизменённых архивов**, не curated extracted subset. Внутри архивов может быть исторический дублирующий source; импортёр проверяет полный SHA/CRC и извлекает только необходимые payloads в текущий проект. Отладочные попытки, дублирующий исходный код и неиспользуемые веса не импортируются. Архивы содержат псевдонимизированные исследовательские user/item IDs исходного публичного набора, не реальные имена. Импортировать следует только доверенные архивы с указанными SHA; модели включают pickle/PyTorch serialization.

```bash
mkdir -p downloads
# Поместите полученные архивы в downloads, затем:
.venv/bin/python scripts/artifacts.py --study 03 --file downloads/study03_artifacts.zip
.venv/bin/python scripts/artifacts.py --study 04 --file downloads/submission_artifacts.zip
.venv/bin/python scripts/reproduce.py tables
```

Импортёр не обращается к прежней рабочей папке. Несовпадающий существующий файл не заменяет. Потребуется дополнительное место на распакованные веса и массивы; предусмотрите около **15–20 GB свободного места** для обоих архивов с запасом, больше для полного обучения. Это рекомендация по свободному месту, не измеренная peak memory.

Для отдельного повторения **только дополнения** нужны frozen inputs из архива study_04; команда `scripts/reproduce.py supplement` заново выполняет pure RL/SFT и оценки. Для replay и точного пересчёта опубликованных чисел нужны также сохранённые outputs/веса. Для `full` готовые архивы **не требуются**: все основные модели/RM обучаются из публичных parquet. Старый frozen GPT прежнего рецепта остаётся дополнительным архивным контролем; полный самостоятельный запуск не притворяется его переобучением.

## Лицензии и provenance

См. [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md). Старые seals сохранены в архивах без изменения, в том числе их исторические пути как метаданные. Проверка никогда не открывает эти пути. Она проверяет импортированные payloads относительно текущего проекта и отдельно сообщает, что source hashes старого checkout не сертифицируют перенесённый код. Новые запуски создают переносимые relative-path seals формата2; Git фиксирует версию новой реализации.
