# Текст для проверяющего

В работе выполнен сквозной offline-эксперимент: последовательная GPT-2 с нуля, непрерывная reward model, REINFORCE с KL, compute-matched supervised-контроли и сильное переранжирование без RL. Чистая GPT-2 и гибрид с фиксированной частотой истории рассмотрены отдельно, на общих контекстах и трёх policy seeds.

Основной результат — управляемый рост модельной награды, сопровождающийся изменением релевантности и структуры выдач. Преимущество RL по релевантности над сильными альтернативами не установлено. Измеренная практическая разница — возможность инференса изменённой политики без RM. Проверка action-sensitive RM выявила существенное ограничение: её качество выбора объектов не подтверждено достаточно уверенно; offline proxy не является доказательством пользовательской полезности или retention.

Study_03 — исходное исследование, study_04 — явно обозначенная исследовательская повторная оценка уже изученного final. Для начала достаточно [README](../README.md); подробности и интервалы — [в отчёте](REPORT.md). Код, конфигурации, малые таблицы и графики включены. Проверены тесты, два маленьких полных конвейера, reconstruction и replay/пересчёт сохранённых результатов; полное исследовательское переобучение при упаковке не повторялось.
